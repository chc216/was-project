## mini java web application server project
Java의 Socket API를 사용해 HTTP 요청/응답을 직접 처리하는
학습용 HTTP 서버 프로젝트입니다.

### 구현내용
- Socket을 이용한 http http/response 로그 출력
- http 표준 규격에 따른 http 파싱 구현
- 요청의 content-type에 따른 body parser를 전략패턴으로 구현

### 추가 구현 예정
- Routing
- Static file service
- implement servlet interface
